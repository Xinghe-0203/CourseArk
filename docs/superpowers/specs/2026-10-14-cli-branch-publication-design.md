# CLI 分支发布设计

## 目标

将当前 AutoChaoxingCLI 项目整理后发布到 `https://github.com/Xinghe-0203/CourseArk` 的 `CLI` 分支。保留当前项目源码和离线测试，排除本地账号、密钥及运行产物，提供清晰的中文 README。

## 发布分支

远程仓库目前只有 `main` 分支，且该分支仅包含 MIT 许可证；远程尚无 `CLI` 分支。本地 `main` 历史包含曾跟踪配置文件的提交，因此不直接推送本地历史。新建的 `CLI` 分支以远程 `main` 为父提交，包含一份经过审查的完整项目快照。此方案保留远程许可证，不改写或推送 `main`，也不会把本地旧历史带入发布分支。

## 文件范围

- 保留应用源码、启动脚本、依赖清单、字体资源和离线测试。
- README 改写为中文项目说明，覆盖功能、环境要求、安装运行、配置和测试命令。
- 清除 `config.yml` 中非空的 LLM API Key；账号密码、会话 Cookie 和第三方令牌不得进入发布内容。
- 从版本控制中排除本地账号文件、题库数据库、日志、缓存、字节码和构建产物，并通过 `.gitignore` 防止再次加入。
- 删除面向编码代理或单次实施过程的 `AGENTS.md`、`CLAUDE.md` 和 `docs/cli-multi-account.md`。保留本设计记录、项目许可证和离线测试。

## 验收

1. `python -m pytest tests -q` 离线回归测试通过。
2. 发布快照不含已知密钥格式、账号库、Cookie、日志或本地数据库。
3. `CLI` 分支基于远程 `main`，包含完整项目和 MIT 许可证；远程 `main` 不变。
4. 推送后检查远程 `CLI` 分支指向本次发布提交。

## 边界

本次只进行发布所需的配置脱敏、文档整理、忽略规则和 README 更新；不改动应用功能。任何 GitHub 身份验证或网络错误均需在推送阶段如实报告。
